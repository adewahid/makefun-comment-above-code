# The Comment Above the Code

One line of commentary for a codebase nobody fully understands anymore. The
vendor behind the endpoint died in 2021, the endpoint never got the memo,
and every engineer who has seen it has quietly decided the mystery is above
their pay grade. It is stinging because it is plausible, and the punchline
lands on the last two words: nobody will ever ask, because asking would mean
owning the answer.

```
 // The vendor went bankrupt in 2021. This endpoint still answers. Nobody has asked why. Nobody will.
```
